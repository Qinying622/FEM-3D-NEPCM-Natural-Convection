# Finite element simulation of natural convection of an NEPCM-water suspension in an enclosure.

| Step                                               | Work required                                                                                                                                                     | Deliverable                                                    |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------- |
| **1. Define the research scope**                   | Fix the research questions, intended contribution, and boundaries of the study.                                                                                   | A short research brief.                                        |
| **2. Complete the focused literature review**      | Compare the closest papers’ geometry, fluids, boundary conditions and findings. Refine the novelty claim.                                                         | Literature comparison table and gap statement.                 |
| **3. Specify the physical and mathematical model** | Define heater dimensions, positions, orientation conventions, thermal conditions, NEPCM properties, assumptions and governing equations.                          | A complete problem specification.                              |
| **4. Audit the existing code**                     | Establish which mesh, flow, thermal and NEPCM components already work and what needs modification.                                                                | Code development checklist.                                    |
| **5. Implement the model**                         | Add parameterised elliptical geometry, boundary tagging, coupled equations and heat-transfer calculations.                                                        | A reproducible baseline simulation.                            |
| **6. Verify and validate**                         | Check limiting cases, benchmark agreement, mesh independence, convergence and energy balance. Check whether selected solutions remain steady under perturbations. | Numerical credibility evidence.                                |
| **7. Run a small pilot study**                     | Compare a few heater orientations and spacings for water and NEPCM, with a latent-heat-disabled numerical control.                                                | An early assessment of the physical findings and contribution. |
| **8. Design and run the main simulation campaign** | Choose parameter ranges based on the pilot, automate runs and record configurations and results consistently.                                                     | The publication dataset.                                       |
| **9. Analyse and explain the results**             | Examine total and individual heater heat transfer, plume interaction, circulation and phase-change activity. Establish useful design conclusions.                 | Final figures, tables and supported findings.                  |
| **10. Write the manuscript**                       | Develop the introduction, methods, validation, results and conclusions; select a suitable journal once the contribution is clearer.                               | A complete manuscript draft.                                   |
| **11. Review and prepare submission**              | Check technical consistency, references, reproducibility and journal requirements.                                                                                | Submission-ready manuscript and supporting files.              |
